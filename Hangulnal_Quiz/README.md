# 세종대왕의 한글날 퀴즈

근정전에서 일월오봉도 앞에 앉은 세종대왕이 직접 묻고 답을 설명해 주는 한글날(10월 9일) 맞춤법 퀴즈입니다. 15문제를 풀면 결과 화면이 뜨고, 기록은 구글 시트에 쌓입니다.

## 파일 (저장소 맨 위 폴더에 올려야 합니다)

| 파일 | 설명 |
| --- | --- |
| `index.html` | 퀴즈 화면 (세종대왕 이미지가 파일 안에 포함되어 있어 이 파일 하나면 됩니다) |
| `Code.gs` | 구글 시트에 기록하는 Apps Script (GitHub에는 보관용, 퀴즈 작동에는 불필요) |
| `README.md` | 이 설명 |

## 구글 시트 연결

1. 시트 1행에 `이름 / 문제1 ~ 문제15 / 맞춘 개수`를 적는다. (A1~Q1)
2. 시트에서 **확장 프로그램 → Apps Script**를 열고 `Code.gs` 내용을 붙여 넣는다.
3. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)로 배포한다.
4. 발급된 `…/exec` 주소를 `index.html` 맨 위의 `SHEET_URL = ''` 따옴표 안에 붙여 넣는다.

기록은 2행부터 쌓입니다. `Code.gs`를 수정하면 **새 버전으로 다시 배포**해야 반영됩니다.

## GitHub Pages로 배포

1. 저장소 **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main` / `/ (root)` 선택 후 Save
3. 1~2분 뒤 `https://<계정>.github.io/<저장소 이름>/` 주소로 접속할 수 있습니다.

## 문제 수정

`index.html`의 `QUESTIONS` 목록에서 문제·보기·해설·근거를 고칠 수 있습니다. 문제 수를 바꾸면 `Code.gs`의 `TOTAL`과 시트 머리글도 함께 맞춰 주세요.
